## 🔍 Cómo Funciona este Jardín

Este sitio no es un CMS tradicional ni una base de datos dinámica:

1. **Redacción en Obsidian**: Escribo y enlazo conceptos localmente en Markdown en mi bóveda de Obsidian.
2. **Sincronización Continua**: Mediante el plugin _Quartz Syncer_, las notas se envían al repositorio en GitHub.
3. **Compilación en la Nube**: GitHub Actions compila el sitio con Quartz 4 y lo despliega estáticamente a alta velocidad.
4. **Grafo de Conocimiento Interactivo**: Puedes explorar las conexiones neuronales entre notas usando el explorador de grafos de la barra lateral.
